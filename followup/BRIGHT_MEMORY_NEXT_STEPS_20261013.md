| 控制与审核结果 | 下一动作 |
| --- | --- |
| 真实检索在损毁相关证据上优于控制，且有纠错机会 | E2：三组匹配的可拒绝 Reader |

这是一轮有限控制，不反复调 K/温度寻找通过结果。Reader 试验不要求裸投票净收益为正；关键是有可利用证据，以及可拒绝误导的设计。

E2 三组为 query-only、T128 Memory、F256 Memory；同容量、同初始化、同训练查询流、同采样/损失、同预算、同 Val 规则。两个 Memory 组共享支持 value 定义，仅改变 key，先固定 Top64。基底为 grid_probq；纠错分支零初始化、空支持回退，拒绝门不能读取查询真实标签。Train 查询仍排除同图/同事件。

验收：Memory 超过 grid_probq 与 query-only，收益依赖真实支持标签；报告损毁类、逐事件、误改，并做随机/打乱/关闭支持干预。Reader 需独立 E2 实现，V3 当前没有训练阶段。此轮不同时加入新 Q、多原型、建筑加权、SAR 投影，也不使用 Test 选方案。
