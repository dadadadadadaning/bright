## 1. 一张地图：每类模块解决什么

影像 → 输入/编码 → 跨模态匹配与融合 → 像素特征 → 可选区域组织/局部读出 → 分类。

Memory是从训练案例补充信息的可选支路；损失与采样决定如何训练；Verifier决定是否接受修改。三者不是区域本身。

| 类别 | 通俗问题 | 不应承诺 |
|---|---|---|
| 输入与编码 | SAR该怎样读？ | 换成单通道就消除传感器差异 |
| 空间匹配 | 该去哪里找SAR响应？ | 低熵匹配一定找对建筑 |
| 表示与融合 | 两种观测怎样共同参与判断？ | 差值就是损毁，共同特征就是纯结构 |
| 区域生成 | 哪些位置暂时放在一起？ | 超像素就是建筑实例 |
| 局部证据读取 | 一组位置中哪些更有判别价值？ | 注意力热点就是实际破坏位置 |
| 分类与监督 | 怎样区分完整、损毁和毁坏？ | 增加尾类权重一定改善精度 |
| Memory | 哪些历史案例能提供额外证据？ | 最近邻一定对应同一种损毁原因 |
| 校验与诊断 | 新建议是否值得采用、为何失败？ | 保守门控本身产生新信息 |

## 3. 五个困难，论文怎样拆开解决

数据口径先统一：BRIGHT的约1像素误差是代理估计；类别比例是建筑像素比例；整栋建筑标签不提供内部精细破坏真值。标准事件内划分和未见事件留出评价不同。[BRIGHT原论文](https://essd.copernicus.org/articles/17/6217/2025/)

### 3.1 模态差异：学习可比较的部分，不是抹平所有差异

| 论文/设计 | 模块怎样工作 | 与你代码的关系与风险 |
|---|---|---|
| [DeCUR，ECCV2024](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/04236.pdf) | 共同/独有嵌入分别承担跨模态相关与互补目标，并用模态内约束防退化 | H2/H3已分支；完整自监督目标不等于现有投影＋正交。变化样本不能无条件当结构一致正对。 |
| [CROMA，NeurIPS2023](https://papers.nips.cc/paper_files/paper/2023/hash/11822e84689e631615199db3b75cd0e4-Abstract-Conference.html) | 光学/SAR编码、对比学习与联合掩码重建 | 借鉴预训练组织，不宜强行对齐所有灾前后样本。 |
| [CMX](https://arxiv.org/html/2203.04838v5) | 双流特征校正、跨注意力与通道融合 | 类似思想已在你多条融合路线出现；原任务不是灾前光学/灾后SAR损毁。 |
| [HeteCD作者项目](https://github.com/weiAI1996/HeteCD) | 非共享双流，特征一致性与时空差异交互 | 你已有H10/CCU/ExternalCD相关实现；必须比较真实启用的模块，不按名称认定完整复现。 |

关键区别：空间匹配回答“在哪里”，共同表示回答“怎样比较”，损毁分类回答“差别是否表示损毁”。三者不能互相替代。特征不一致还可能来自时间、材质、视角、噪声；仅靠两个输入不能宣称完成物理因素分离。

### 3.2 错位：局部搜索、位移采样和图像配准不是同一个操作

[RIFT](https://arxiv.org/abs/1804.09493)用结构性关键点与描述子降低辐射差异影响；[XoFTR](https://arxiv.org/abs/2404.09692)研究跨模态粗到细匹配，主要设置为可见光/热红外；[SAR–Optical匹配评测](https://arxiv.org/abs/2604.10217)比较预训练匹配器，提示效果依赖任务协议，不能直接假定一种匹配器通吃。

你的LCA属于局部特征取证，AL/H4含偏移采样。3×3必须注明是哪个特征层：特征图1格不等于原图1像素。低熵只说明权重集中；选中邻楼也可能低熵。验证对应必须另看已知人工位移恢复、真实匹配可视化和未扰动损毁表现，不能只看attention热图。

### 3.3 超像素和局部证据：先分组，再读证据，二者独立

| 论文 | 分组或读出机制 | 对你最有用的区别 |
|---|---|---|
| [SSN，ECCV2018](https://openaccess.thecvf.com/content_ECCV_2018/html/Varun_Jampani_Superpixel_Sampling_Networks_ECCV_2018_paper.html) | 学特征后局部软聚类，迭代中心，可反传 | 接近迭代分区思想；固定颜色距离不是完整SSN。 |
| [SpixelFCN，CVPR2020](https://openaccess.thecvf.com/content_CVPR_2020/html/Yang_Superpixel_Segmentation_With_Fully_Convolutional_Networks_CVPR_2020_paper.html) | FCN直接预测邻近中心归属，支持池化/上采样 | 接近直接软关联头；不必等同于迭代聚类。 |
| [Superpixel Transformers，IROS2023](https://arxiv.org/html/2309.16889v2) | 局部双向交叉注意力更新像素和区域，再区域自注意力与软回投 | 不只是均值池化后接分类器；也不保证弱证据保留。 |
| [ChangeOS](https://www.sciencedirect.com/science/article/pii/S0034425721003564) | 学习建筑定位和损毁，按对象组织输出 | 光学双时相，不是RGB–SAR；建筑对象不同于通用超像素。 |
| [ABMIL](https://proceedings.mlr.press/v80/ilse18a.html)、[DSMIL](https://openaccess.thecvf.com/content/CVPR2021/html/Li_Dual-Stream_Multiple_Instance_Learning_Network_for_Whole_Slide_Image_Classification_CVPR_2021_paper.html) | 局部集合→注意力或关键实例关系→整体标签 | 你已有DSMIL、soft-critical，不宜再次建议原样加入。 |
| [CLAM](https://www.nature.com/articles/s41551-020-00682-w) | 除袋分类外，对代表局部施加聚类约束 | 病理弱监督借鉴；不能把被选择局部当真实损毁标注。 |

区域本身不消除传感器差异：它只改变哪些特征一起计算。若输入已被错配污染，平均池化、峰值和图传播都可能放大问题。

### 3.4 Memory：取什么、怎么比、怎么用必须分别验证

| 论文 | 核心设计 | 你已做到哪里 |
|---|---|---|
| [RAC，CVPR2022](https://openaccess.thecvf.com/content/CVPR2022/html/Long_Retrieval_Augmented_Classification_for_Long-Tail_Visual_Recognition_CVPR_2022_paper.html) | 外部图像/文本支持参与长尾分类 | 不能据此推导BRIGHT跨事件支持一定有效。 |

| [DeepEMD，CVPR2020](https://arxiv.org/abs/2003.06777v1) | 交叉参考重要性与EMD匹配局部结构 | CMR均匀Sinkhorn是相关实现，不是完整方法与训练。 |
| [FRN，CVPR2021](https://openaccess.thecvf.com/content/CVPR2021/html/Wertheimer_Few-Shot_Classification_With_Feature_Map_Reconstruction_Networks_CVPR_2021_paper.html) | 支持特征重建查询，以误差判类别 | CMR已实现ridge重建思想，不能再当未试过的新距离。 |

SRAC的超像素＋检索路线和录用信息由[作者单位报道](https://jianghai.ucas.ac.cn/index.php/zh/xshde/xsdte/461-igarss-2026)及会议列表支持；本次未取得可核验全文/官方代码，不能断言完整技术相同或完全避开。

### 3.5 长尾和跨事件：优化问题不一定需要新增推理模块

[Decoupling](https://openreview.net/pdf?id=r1gRTCVFvB)分开表示学习与分类器平衡；[Balanced Meta-Softmax](https://proceedings.neurips.cc/paper_files/paper/2020/hash/2ba61cc3a8f44143e1f2f13b2b729ab3-Abstract.html)调整类别先验作用，完整方法不只一个损失；[BLV](https://openaccess.thecvf.com/content/CVPR2023/papers/Wang_Balancing_Logit_Variation_for_Long-Tailed_Semantic_Segmentation_CVPR_2023_paper.pdf)在训练时按类别频率施加logit扰动。你的探针、BalancedSoftmax、BLV已有对应尝试。

[OGM-GE](https://arxiv.org/abs/2203.15332)处理模态优化失衡；[PCGrad](https://proceedings.neurips.cc/paper/2020/hash/3fe78a8acf5fda99de95303940a2420c-Abstract.html)处理共享参数上的任务梯度冲突。两者不是一回事，也不是看到两个分支或两个loss就应该加。你部分路线冻结RGB，定位损失可能根本不更新共享主干；这时不能用任务冲突解释失败。

跨事件还包括采样、风格、度量和评价。OABH有风格适配、RM5有同类异事件对比、CMR有事件中心化，Verifier有GroupDRO/V-REx。检索时排除同事件，只约束支持来源；不能证明编码器没见过该事件。

以下是此前已核验记录的汇总，本轮未重新跑评估；详细来源见[前次研究路线报告](D:/software/dowmload/BRIGHT-master/research_reports/BRIGHT_研究路线总梳理与修改决策_20260929.md)。

## 5. 怎么选下一步：只保留三个条件分支

不要再把本报告的模块拼成一个大模型。先确定缺口在哪，再只改该处。

### 方向一：表示是否缺少独立的损毁证据

- 条件：完整训练/验证覆盖的冻结读出仍不能区分Damaged→Intact与真实Intact。
- 候选研究题意：完整建筑锚定的跨模态共同与互补损毁表示。
- 模块输入：同尺度RGB/SAR特征；输出：共同结构、各模态保留特征及损毁预测。只对可信完整样本施加跨模态共同约束；分类仍能读取独有信息。
- 与旧版比较：H2/H3/IARM/AL，明确新增的是哪一种目标和梯度路径，而非重命名分支。
- 风险：完整预测污染、表示退化、真实变化被统一。难度高、训练成本高，目前不能保证收益或新颖性。

### 方向二：信息存在，但区域读出丢失它

- 条件：同特征像素读出优于区域读出，且匹配容量、训练长度、采样后差距仍在。
- 候选研究题意：保持像素细节的区域交互式损毁学习。
- 输入：像素特征与软关联；操作：双向像素/区域交互；输出：保留像素通路的密集分类，而非整栋硬广播。
- 与旧版比较：Joint、MICB、H13、S2蒸馏以及已存在的attention；不能只比最弱均值池化。
- 风险：训练信号本身不足、容量收益、区域错误传播。中高成本；如果差距已由普通上下文解释，应停止包装自适应分区创新。

### 方向三：表示有用，但Memory来源或使用有问题

- 条件：检索错误真实触发，或公平建库/同特征分类证明支持信息有增量。
- 候选研究题意：面向跨事件证据覆盖的区域案例学习。
- 固定Key先修有效邻居mask、独立案例、全池图像覆盖；比较原库/公平库及真实/乱标签支持，再决定是否训练Key。
- 与旧版比较：Exemplar、Factorized、CMR、RM5和Memory roles；DN4/OT/FRN不是新的起点。
- 风险：支持仍按事件外观匹配。缓存审计成本低，度量重训成本中等；修bug是必要工程，不自动构成论文贡献。

这三个是诊断后候选，不是要求同时做三套。现有证据不足以给可信成功概率，也不足以宣称某条有可发表创新。

## 6. 每个后续模块只填写这一张卡

1. 目标错误：例如Damaged→Intact，不只写提高mIoU。
2. 输入/输出：具体层级、维度、分辨率、区域来源。
3. 操作：改变读取位置、改变表示、改变聚合还是改变分数？只能先选主要一种。
4. 监督：哪些标签、在哪些像素计算、梯度更新谁？
5. 推理：是否需要Memory、额外编码器或实例分割，是否使用训练时才有的信息？
6. 对照：父模型、等训练、等容量、已有最接近版本。
7. 判断：Damaged精确率/召回/F1、D→I、Intact误报、分事件结果与重复运行稳定性。
8. 停止条件：若新增模块收益被采样/容量解释，或支持打乱后不变，不再继续叠层。

## 7. 尚未知道什么

尚未为每个静态实现绑定唯一完成日志和checkpoint；未重新验证所有历史评价样本；SRAC全文不可核验；没有用实验确认“传感器差异”与“真实损毁”已被分离。以上限制应保留在研究讨论中，而不是用复杂模块名填补。

**最终结论：先把已有模块归位，再找一条实际断掉的信息链。你的下一步应是证据驱动地选一个作用位置，不是继续收集插件。**
