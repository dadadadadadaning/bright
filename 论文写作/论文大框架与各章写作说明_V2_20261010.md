# 论文大框架与各章写作说明

## 一、全文要回答的核心问题

这篇论文按方法论文组织。研究对象是灾前光学与灾后SAR输入下的四类建筑损毁分割；核心问题是：如何利用建筑结构组织融合特征，并把区域内的信息转化为可靠的等级判断？

建议保留题目“建筑结构引导的光学–SAR区域表示与建筑损毁等级判别”。当前标题覆盖实际实现，不提前宣称精度领先、跨事件泛化或实例级损伤重建。

全文论证顺序为：任务与现有基础 → 区域组织和信息汇总的具体问题 → 两部分方法 → 整体与组件对照 → 条件和边界。读者读完引言，应知道后面为什么需要这些模块；读完实验，应知道哪些主张得到支持、哪些尚需验证。

两个技术挑战分别对应两部分方法。挑战一是“哪些位置共同提供判别信息”，对应光学软归属与预测建筑分组；挑战二是“区域内的信息如何保留并用于分类”，对应注意力、统计补充和概率回投。双模态骨干与Soft ROI是基础内容路径，不宜将继承的每一层都包装为独立创新。

贡献宜写三项：结构引导的区域组织、与像素任务一致的区域读出、针对结构与任务效用关系的受控分析。前两项先描述设计本身，是否提升要由主比较与消融确认；第三项限定于当前已经完成的分区学习设置。Memory移至附录，保留扩展价值，正式结果形成前不列为核心贡献。

## 二、七章分工与详细写法

### 第1章 引言：建立问题与方案的对应关系

本章回答“为什么研究，以及本文具体做什么”。正文保留六个连续段落，不为每个段落设置小标题。

第1段写应用与输入。用建筑损毁评估的实际信息需求引出灾前光学、灾后SAR组合，再以BRIGHT说明已有研究基础。支撑材料是任务和数据集原始文献。不要从泛泛的深度学习发展史写起。

第2段写现有能力与进一步要问的问题。承认对象先验、Transformer和状态空间方法已经利用上下文，再聚焦“融合特征如何共同汇总”。支撑材料是代表性方法及其真实机制。不能为了引出区域方法，将现有工作笼统写成没有上下文或不利用建筑结构。

第3段用一句话给核心思路，再解释研究范围。建议句式：“本文以光学结构生成局部关联，以融合特征提供分类内容，并在预测建筑约束下形成区域表示。”本段只说明研究对象，不展开公式或训练参数。

第4段写两项挑战。第一项是空间关联与预测建筑约束，第二项是压缩后信息的保留。每项先说明直接做法的不足，再指出要处理的关系；定位错误作为边界，不能暗示已有方法能够修复所有定位错误。

第5段顺着数据流概述方法。光学描述 → Q → 建筑分组 → 注意力与统计 → 区域概率 → 像素回投。只解释各步骤的目的，不逐层列网络结构。

第6段写三项贡献。每项对应方法或实验中的具体位置。当前用“构建”“给出”“报告受控观察”，不要写尚未证实的“显著提升”“全面优于”。Memory不进入贡献列表。

完成标准：六段读下来能够自然推导第4章的两部分设计；贡献中的每个判断都能在第5章找到对应比较。引言不提前分析分区学习失败原因。

### 第2章 相关工作：明确与已有方法的关系

本章回答“已有方法做到哪里，本文考察哪一层问题”。按三个主题写，每节遵循“研究路线 → 代表方法 → 与本文关系”的顺序，避免逐篇摘要罗列。

2.1 建筑损毁评估与跨模态表征。先概述定位与等级分类，再交代光学–SAR任务和已有基础模型。材料包括xBD、BRIGHT、ChangeOS、双任务Transformer、ChangeMamba及骨干文献。段末落到本文研究既有融合特征之上的区域组织，不能将不同输入条件的论文成绩直接比较。

2.2 从固定超像素到可学习分区。先讲外观与空间邻近规则，再讲可微分区与任务监督。材料包括SLIC、SSN、全卷积超像素与分割感知亲和性学习。需要区分“分区可以学习”和“继续学习能改善当前任务”；后一项要由本研究实验判断。

2.3 区域上下文与内容汇总。交代区域表示怎样形成、如何作用于像素预测，以OCR和Superpixel Transformers为主要参照。WANet只用于说明任务特点与表示设计的对应，不把小波模块迁移写成本文贡献。此节结尾引向注意力、统计及回投的设计。

材料要求：每条机制陈述对应原文或摘要；引文指向所描述的版本。本文已核验的文献可继续使用，不因目录调整而凑数增加参考文献。

完成标准：读者能分清本方法与分区生成、对象上下文和外部记忆的关系。历史支持文献集中到附录，不与正文主线并列展开。

### 第3章 任务定义与数据基础：固定研究和评价范围

本章回答“输入输出是什么、数据是什么、哪些判断可以被标签验证”。它承担任务定义，不承担新数据集贡献，也不重复引言的背景。

3.1 输入、输出与区域单元。说明输入配对、四类概率和最终损毁图，明确区域是计算单元。需要任务配置与标签含义支持。要写清区域、建筑实例和建筑内部损伤部位的区别，避免后文把区域可视化解释成真实损伤分布。

3.2 BRIGHT数据与标准划分。给数据来源、覆盖范围、分辨率、样本划分及各集合用途。数据集总体信息来自原论文，2918／450／878来自项目实际清单计数，两类来源不混淆。预留图1、表1；类别比例和事件构成只在实际统计后填写。

3.3 研究假设与评价边界。写两项工作假设：结构约束可能改变共同汇总关系；注意力与统计可能提供不同于平均特征的信息。说明将通过哪些比较检验，而非把假设写成已知结论。最后统一交代真值仅用于监督或离线诊断、对象代理的限制和全图评价口径。

完成标准：第4章的Q、建筑概率B、融合内容Z和区域表示均有明确任务含义；第5章任何使用真值的子集统计都不会被误读为推理输入。

### 第4章 方法：沿数据流解释每个设计

本章回答“方法怎样运行，别人如何复现”。每节按“目的 → 输入输出 → 计算过程 → 实现边界”展开。参数只写一次，实验设置引用对应配置，不在多个章节重复。

完成标准：读者能够从输入追踪到输出，每个符号都有定义，每个有意设计都有第5章中的直接对照。方法章不写尚未验证的性能结论，也不以训练历史替代机制说明。

### 第6章 讨论：解释现象与适用边界

本章回答“为什么可能出现这些现象、结论适用到哪里”。数据事实引用第5章，解释使用“可能”“与……一致”“尚不能区分”，不重新列一遍结果。

6.1 区域结构与等级信息的区别。讨论区域相容性、融合特征可分性和读出保留信息之间的关系。把候选解释与可区分它们的对照对应起来，不凭一个负结果确定唯一原因。

6.2 预测建筑约束的适用条件。讨论Soft ROI与硬分组的不同作用、定位错误和跨模态响应范围。预留图6展示失败案例。若没有定位修复或配准机制，就不将它们写成已经解决的问题。

6.3 标签语义与结论范围。统一说明区域不是实例、区域统计不是局部真实损毁比例、标准划分事件分析不是未见事件泛化。本节集中放解释边界，减少其在方法和实验中反复出现。

6.4 尚需闭合的验证环节。指出整体预算匹配比较与读出消融是当前最直接的缺口，再引向附录A的扩展。后续方向按已有错误和证据决定，不把可以加入的模块列成创新清单。

完成标准：讨论增加解释价值，但没有超出实验的因果证据，也没有引入正文方法从未实现的新机制。

## 三、核心主张分别怎样支撑

主张一：整个区域路径有实际价值。直接依据是预算匹配系统比较，并辅以同一冻结前端的像素／区域读出比较。前者检验整体系统，后者检验读出方式；两者不能互相替代。可视化只说明变化位置，不能独立完成这一证明。

主张二：结构引导的关联起作用。最小设计是规则网格／预学习Q与无分组／预测B分组的交叉比较。固定内容和读出，记录有效槽位、混合统计及定位子集。若强调建筑语义而非容量，还需2K非建筑空间分裂参照；简单复制同一槽位不是充分参照。

主张三：注意力和统计补充有作用。最小设计是Q加权均值／学习注意力与无统计／均值加标准差的四组组合。固定Q、B、内容与训练预算。只有进一步比较均值旁路和均值加标准差旁路，才能把增量专门归因于标准差；必要时加相近容量的重复均值输入旁路。

主张四：结构统计不能替代最终任务评价。已有三组分区继续学习实验支持当前设置下的具体观察。需要同时保留统一终点结果和同等级支持统计，说明Q确实更新且公共前端未更新。不能外推所有可学习分区无效，也不能把细小变化称为统计显著。

主张五：方法在某些条件下受限。依据定位、边界、尺度和事件子集，以及同一批样本的修复与新增错误。子集相关性只能帮助定位问题；若要作因果解释，还需与对应机制的直接消融联合。

以上属于经验支持，不是数学意义上的普遍证明。每项结论都应包含适用的数据、训练和比较条件。

## 五、接下来怎样完善正文

第一步，锁定主张和比较对象。明确主结果是完整系统比较还是固定前端的读出比较，两者各自保留来源记录；此时先不扩大模块数量。

第二步，优先补完整主比较和关键读出消融。它们分别支撑整体价值与方法设计，是目前证据链中最直接的缺口。确认比较规则后再运行，避免事后依据最好验证点更换标准。

第三步，把已有Q学习结果整理到表5，并保留与任务指标一致的结构统计。随后按主比较及消融中真实发生的错误选图4至图6，保证成功与失败案例均可追溯。

第四步，补必要的稳定性和完整开销。敏感性只围绕主要机制展开；若核心增益无法复现，不用堆叠更多参数搜索掩盖问题。

第五步，更新第5章的结果段、第6章解释，再最后重写摘要和结论。文字顺序建议为第3章 → 第4章 → 第5章 → 第6章 → 第2章 → 第1章 → 第7章 → 摘要，避免尚无结果时先固定过强的摘要结论。
