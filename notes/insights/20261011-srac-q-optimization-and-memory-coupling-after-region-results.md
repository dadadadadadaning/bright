# 当前 SRAC 软超像素 Q 如何优化，及如何接跨事件 Memory

日期：2026-10-11。范围：结合用户给出的 Val450、Test878 冻结结果，核查本地 SRAC 代码，并检索超像素学习与区域标签迁移的论文及作者代码。本次没有运行新模型或服务器数据，以下新结构均为待验证假设。现有 P/R/T 实验尚无用户提供的完整正式结果。

## 最重要的判断

现有 Q 已证明在既有像素概率上有图内共享价值；实际 `region` 下降主要指向整条 `T128 + 分类头 + 回投` 路径，不能从表中单独归咎于 Q。下一轮先完成固定 F/Q 的 P/R/T 对照和 Q 混合度审计，再决定是否训练新 Q。Memory 需要把“图内共享单位”和“历史案例单位”分开：Q 可以继续作局部交流网络，支持条目可以在 Q 内按预测建筑概率加权或按预测建筑候选拆分。

另一个此前容易遗漏的事实：当前 Q 只依赖灾前 RGB Swin 特征和灾前光学建筑概率；灾后 SAR 的损毁特征进入后面的区域表示，但不直接参与 Q 打分。这适合找建筑结构，却不能要求 Q 凭空识别灾后才出现的损毁差异。若量到前景损毁类别混合，新增双时相/融合特征线索应与新增监督损失分开消融。

## 当前 Q 与 Memory 的真实连接

`DamageFormer_S8_MICB_DSMIL.py:595–604`：冻结 A1 从灾前 RGB 产生建筑概率 B，并以 `alpha+(1-alpha)B` 作用于光学/SAR融合损毁特征 F。`srac_transformer_v1/model.py:401–405`：独立 RGB Swin 特征解码成结构图 E，Q 从 E 与 B 产生。`model.py:107–151`：每个特征格点考虑附近九个种子，三轮更新；分数由 E 相似性、空间距离、建筑概率相容性构成，得到稀疏软 Q。默认 `stride=8` 是特征格间距，不能说原图每八像素一个区域。`B.detach()`，冻结 A1 定位头不会被 Q 的损失直接改写。

源码中的最高分辨率 RGB 特征与融合 F 均约为原图四分之一宽高；因此默认 stride=8 对 1024 图像约对应 32 原像素的**种子间距**、约 1024 个种子。软 Q 的实际区域可以变形、重叠，不能读成固定 32×32 原图方块；有效区域数应以本次 checkpoint 和张量为准。

`model.py:285–301`：区域 T128 主分支在 Q 外乘可学习空间权重，同时注入由原 Q 形成的均值/标准差、几何等。`common.py:160–171`：Memory 的 Train 软标签是按原 Q 汇总的四类像素比例。因此“主特征更侧重区域左侧、标签按全区域面积统计”的失配可能出现，但尚未测实。`build_memory.py:115–139` 默认允许混合区域，按主类做事件×类配额；四维软标签仍保留，不等于全库硬标签。

`joint_context_v1/model.py:215–247`：旧 J1/J2/J3 将增强后的区域 T 经同一 Q 回投为像素上下文，与原像素特征一起分类。同一 Q 区域内可以输出不同类别。旧模型没有把 `grid_probq` 当固定基线，旧 J3 分数无法视为“61.8382%再加 Memory”。

## 第一层：先判断是否真的需要更改 Q

同一验证前向，GT 仅用于预测/检索固定之后的审计：

1. 对每区域分别统计前景质量、建筑/背景混合、前景三类条件纯度、小建筑覆盖、质量大小；对像素同时给出硬归属分层与 **软 Q 暴露度**。硬分区可视化不显示第二、第三候选的跨界质量。
2. 单独检查冻结 B 在完整、损坏、毁坏建筑上的召回及边界误差。B 预测漏掉建筑时，提高其硬约束会放大漏检。
3. 做 GT 语义汇总回投诊断：有效 one-hot GT 以 `area` 对齐到 Q 网格，按 Q 求区域比例，再按同 Q 回投。与“仅 area 降采样/上采样”对照，分离网格分辨率损失与 Q 混合损失。这个 GT oracle 是诊断，不是模型成绩、J1/Memory 性能上界。
4. 按 Intact→Damaged、Damaged→Intact/Destroyed、边界/内部、事件分层，比较高混合区与低混合区的错误率及 Memory 救回/伤害。分层相关性不是因果；若错误在纯区同样严重，优先查表示或检索。
5. 完成当前固定 F/Q 的 P/R/T 等预算训练。初始 Val450 必须先满足旧五臂绝对 `1e-5` 复现；只看 smoke 或单张复检不能判决。P/R 匹配地检验均值区域表示，T 是不同维数的辅助判断。

关键分叉：若 Q 的 GT 回投保留损毁边界较好、R 适配后改善，保留 Q；若 GT 回投本身在前景不同类别边界损失大，再开新 Q 分支。若主要是纯区检索错类，改检索键和困难负例而不是 Q。

## 第二层：如果 Q 确有语义混合，怎样改

只做可归因的两个主变量，不直接把 `building_weight` 调大：

- **Q-S：新增区域语义重建损失。** Train 四类真值转成特征格软 one-hot，忽略 255；经 Q 汇总得区域标签，再按 Q 回投，在有效格点对原软标签计算交叉熵。也可单独比较二值建筑重建。配空间坐标重建或非空质量约束，避免为了纯度把区域切得极碎。GT 只作损失；Val/Test 的 Q 前向不读真值。原 `train_front.py` 仅最终 NLL＋Lovasz；仓库旧 `a1_cross_modal_superpixel_v1/losses.py` 有建筑重建、边界亲和实现，但并未用于当前 SRAC。**只调辅助损失时，Q 仍仅看灾前输入，可利用已可见的建筑边界，但无法凭空读取灾后改变。**
- **Q-F：给 Q 一条轻量双时相损毁线索。** 保持当前 E/B 和九候选、种子数、迭代方式，增加冻结 A1 融合特征 F 的小投影，在特征格与 E 融合后形成查询/中心相似性。用可学习且初始很小的强度控制新线索，单独训练/验证；先不用 A1 硬类别来划分，避免其漏判直接锁死 Q。要注意 F 已受 B 调制，先分析 B 漏楼。实验采用输入来源（灾前／灾前＋F）×损失（原损失／原损失＋语义重建）的 2×2 设计，统一训练预算、种子预算和读出头：这样 Q-S、Q-F 与两者组合都能从相邻单变量对照判读。

仓库已有**独立实验家族** `damageformer_rgb_anchored_change_superpixel_v3`：`README_ZH.md` 写出 RGB 结构锚定＋有界对齐变化修正，`losses.py` 有损毁语义重建和按**全局区域 ID**计算邻域共属概率的边界损失，并包含打乱 SAR 的负对照。另一个 `damageformer_building_internal_change_partition_v2` 实现预测建筑候选内的变化分区。这些是本地设计/代码参考，不是当前 SRAC Q 已启用的功能，也没有本轮可直接与 SRAC 比较的匹配成绩；不能复用其权重或直接拼进已冻结的 SRAC 运行。当前 SRAC 标签用 `area` 降采样，旧 V3 损失用了 `nearest`，移植前还需检查小建筑与 ignore 区域的差异。

当问题集中在小建筑且面积降采样对照已排除前端分辨率瓶颈时，再试 stride 从 8 到 4。理论种子数约乘四，需测实际有效区域数、时间和 Memory 每事件候选覆盖；仅改 stride 不会恢复上采样前已丢失的信息。若区域完整但面积过大，可优先在 Memory 条目侧加入细局部，而保留图内 Q。

## 第三层：在现有 Q 上先改 Memory 的“案例卡”

现有 Q 可继续承担图内共享。首先检查当前 T128 主特征使用 `Q×学习空间权重`、标签使用原 Q 的失配是否真的影响近邻标签相容性。可以在同一 Q 内让支持特征与 Train 软标签都按相同的空间权重统计；但学习权重也可能偏向错误位置，需要与原 Q 均值键及原标签对照。若诊断显示**建筑/背景混合**是主要问题，再试较容易解释的建筑概率权重：

`W_ir = Q_ir * [eps + (1-eps) B_i]`, `0 < eps <= 1`。

用**同一 W** 提取双时相损毁特征键和训练软标签（忽略 255 后使用一致的有效质量分母）；以 `eps=1` 作为原 Q 面积聚合对照。`eps<1` 是关注建筑、又不给定位漏楼处完全清零。先固定同一批 Train 支持行、容量和事件×类配额，测新旧描述的 Top-8/64 相容性；必要时另设背景支持，而不是无记录地删除背景类。只看更高纯度不够，还要看困难 Intact 是否被错检为 Damaged、漏判 Damaged 的可靠支持在库/Top64/Top8出现率。**这项建筑加权主要治理道路混入；若主要问题是真 Intact 被错检为 Damaged，而两边 B 都接近 1，则它通常不是主要解法。** 此时优先检查表征是否含双时相损毁线索、特征/标签同域汇总是否改善，以及检索投影能否排开外观相近的 Intact／Damaged。

在这里 `Q*B` 是**区域内的描述权重**。如果每个像素又在所有区域上归一化，公共 `B_i` 会抵消，Q 并没有变。它也不能分开两栋都 `B≈1`、损毁程度却不同的建筑。

诊断阶段优先对比同维度的 `F` 均值键：Q 权重与 W 权重都得到 256维向量，用同一余弦/同一跨事件排除与支持行测检索。原 J3 投影和 Reader 接受 T128；新 F256 不能直接塞进 T128 Reader。若新键确实改善困难查询，再为旧/新路径以相同预算适配投影与 Reader，或单独测试只更换原 T128 所附标签的干预并正确注明其局限。不要将固定 Reader 对分布外新键的失败直接解释为新库无用。

若审计明确显示一个 Q 块跨越不同建筑类别，再引入同一方法预测的实例候选 `M_ib`，建立 `W_irb=Q_ir*M_ib`。一栋允许多个局部条目；查询和支持都按同样方法生成，Train GT 仅用于标注支持。现有二值概率连通域会把相邻楼合并，只能作低成本候选。对象票决须等实例质量验证，不直接套到四类像素图。

检索建议保持双时相特征为 key，保留事件/图像排除、软标签和绝对相似度。回投仍由 Q 或其预测实例交集把**参考上下文**送回像素分类，不能把 Top-8 的 Damaged 标签硬涂在整个区域或候选楼上。当前偏好是不训练采纳/拒绝门控；检索质量与读取效果单独报告。

## 最小可复现实验矩阵与判据

| 序号 | 固定条件 | 变化 | 主要判据 |
|---|---|---|---|
| D0 | 已通过 E0 数值协议，冻结旧 F/Q | 完成 P/R/T + Q/GT 混合审计 | R vs P；类别边界损失是否来自 Q |
| M1 | 旧 Q、同 Train 行和容量 | Q 均值键/标签 vs 当前学习权重对齐键/标签；背景稀释明显时再试建筑加权 W | 困难 Intact/Damaged 的库、Top64、Top8支持覆盖及错类率；不涉及 Reader |
| Q1 | 同前端、种子数、训练预算、无 Memory | 旧 Q vs Q-S，Q-F 单变量消融 | Q 的语义压缩、四类 IoU、事件泛化、有效区域数 |
| M2 | 各自匹配重建支持/查询 | 旧/新 Q × 无/有 Memory | 救回、伤害、非 Damaged→Damaged 假阳性、四类 IoU及逐事件结果 |

所有新 Q 或 token 都要重新生成 Train 库和 Val 查询，并检验投影与 Reader 的输入空间。不同 Q 产生不同区域集合，不能声称支持“完全相同”；需保持选样算法、容量、事件×类配额、训练预算和数值协议匹配。旧 J1/J3 各自训练，最终差值不能当作单独检索的因果效果；同一模型的支持开/关可作推理干预，且标明 support-off 不等于重新训练的 J1。

选设计用 Train/Val；历史 Test878 作为已观察到的冻结结果，不反复用于挑选超像素权重。`1e-5` 历史复现门槛、失败报告和正式完整性检查保持不变。前期已有概率归一化偶发失败，须先由正式初始 Val 和诊断记录确定是否通过，不要让这类数值问题污染结构改动比较。

## 可研究的三个具体题目

1. **面向建筑损毁的双时相任务超像素与固定区域头评估**：在 BRIGHT Train/Val，比较灾前 Q、双时相 Q、语义重建 Q；核心贡献需证明分类与检索同时受益，而非只显示分区图更整齐。成本中高。
2. **同 Q 下特征—标签同域汇总的跨事件损毁案例库**：固定前端 Q 与候选数量，对均值、学习权重对齐和条件性建筑加权的支持键/标签作匹配比较；若困难 Intact/Damaged 的近邻质量改善，再做匹配 Reader。成本中。
3. **建筑候选内多局部超像素 Memory**：预测实例候选和 Q 相交，记录每栋多个局部支持，分析合并/漏检错误与误报。需要额外可靠实例候选；成本高，作为条件性后续。
