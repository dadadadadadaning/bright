## 一句话回答是否在A1基础上加超像素

是，但分两次训练：第一次从A1权重出发，加入可学习分区、图像调制和区域分类，联合更新模型；第二次取其中的3000步快照并冻结，重新训练raw、roi、normal三个区域读出，检查内容来源。

## 原始A1做什么

按当前代码和既往记录，A1是含建筑Soft ROI路径的DamageFormer。灾前RGB和灾后SAR分别编码，RGB定位分支预测建筑概率B，融合特征经过ROI调节后交给像素分类头。

```text
灾前RGB → RGB Swin → RGB特征 ─┬→ 定位头 → 建筑概率B
                             |
灾后SAR → SAR Swin → SAR特征 ─┴→ 融合 → Soft ROI → 像素分类
```

本地这一版本的ROI表达式为F_roi = F_fused * (0.1 + 0.9 * B.detach())。低建筑概率位置被衰减，高概率位置接近保持原幅度。它并非“背景保持1、建筑额外放大”的表达式；应以实际版本为准，不能根据Soft ROI名称推定公式。

A1像素路径没有Q区域汇总；不代表它完全没有上下文，因为Swin和融合网络已经进行特征交互。

## 第一次如何把超像素加到A1

四阶段V2保留A1模块并新增以下路径：

| 部分 | 来源 | 用途 |
|---|---|---|
| RGB与SAR Swin、融合层 | A1权重初始化 | 提取跨模态内容 |
| 定位头和原像素头 | A1权重初始化 | 建筑定位和像素辅助监督 |
| 嵌套解码器与局部聚类 | 新增 | 生成区域软归属Q |
| RGB图像调制与再次编码 | 新增流程，复用RGB编码器 | 生成区域路径的内容 |
| 注意力Pooling和mean/std旁路 | 新增 | 形成区域Token |
| 区域四类分类器及回投 | 新增 | 产生最终region预测 |

分区使用RGB多尺度特征，经32通道轻量嵌套解码器，按特征图stride8设置初始格子，每个位置考虑附近9个中心，依据特征余弦相似度与空间距离做三轮软归属更新。每个位置的9个权重之和为1。

stride8是特征网格单位，不是原图8像素。Q不是建筑实例标签。该四阶段调用传入全零建筑分组，故没有建筑与背景硬隔离，也不保证每个硬区域连通。

```text
RGB原图特征 → 嵌套解码器 → Q ──────────────────┐
                         → 硬边界             |
定位头 → B ───────────────→ RGB压暗及边界提亮   |
                                  ↓           |
                           共享RGB Swin重编码   |
                                  ↓           |
                       与原SAR特征融合         |
                                  ↓           |
                         按Q汇总区域表示 ←─────┘
                                  ↓
                         区域概率 → 按Q回投
```

区域主表示是Q与空间注意力共同加权的特征均值，另加Q加权mean/std投影旁路，经过归一化、四类分类。每个像素依据Q混合附近区域的四类概率，再上采样。它不是一个区域必须整块输出一个硬类别。

### 联合训练更新了什么

四阶段A1初始化分支默认原有模块学习率1e-5、新增模块1e-4；本地训练目标为定位CE+Lovasz、区域NLL+Lovasz以及0.25倍像素CE+Lovasz。编码器、融合层、分区解码器和区域读出共同训练，像素头也接受辅助损失，相关运行统计可更新。

B用于ROI/图像调制时detach，硬边界也detach；这不代表编码器冻结，因为其它可微路径仍更新共享参数。

所以训练后的内部pixel不保证保持原A1精度。它下降的具体原因仍需受控实验，不能仅凭共享权重就断定是BN或梯度冲突。

### 最终输出不是像素与区域相加

当前V2的最终region来自区域概率回投。pixel用于辅助监督和评估参照，不直接参与最终region相加。之前T3的像素加区域残差是另一条历史实验路线，不能拿来描述当前V2。

## 当前三组内容实验的具体设计

实验代码目录：bda_benchmark/experiments/damageformer_region_content_v1。

前端、Q、定位、旧pixel/region、BN统计均冻结，三个新区域读出同初始化但参数独立。各自包括完整注意力Pooling、mean/std、区域分类与回投。

| 名称 | 给区域的内容 | 是否使用Q | 本轮是否学习Q |
|---|---|---|---|
| raw | 原图RGB与SAR融合特征，不额外乘当前Soft ROI | 是 | 否 |
| roi | 同一原图融合特征乘原Soft ROI，是原像素头精确输入 | 是 | 否 |
| normal | RGB经过图像调制再编码，与SAR融合后的特征 | 是 | 否 |
| old_pixel | 固定快照原像素预测，仅记录 | 否 | 不适用 |
| old_region | 固定快照原区域预测，仅记录 | 是 | 否 |

raw不等于无超像素，也不等于整个历史训练没有使用ROI。三组都从同一历史前端提取特征。图像调制与Soft ROI不是同一种处理。

训练为5000优化器更新，EBS16，各读出80000个裁剪，共用相同批次；AdamW、100步warmup和余弦衰减，原区域NLL+Lovasz。每500步完整Val450，不访问Test。

## 这些结果能说明什么

已支持：相同Q与读出结构下，本次训练的原图内容持续优于调制内容；当前Q能够支持有效分类；roi未显示相对raw稳定额外优势。

尚未支持：超像素相对同容量像素头必然有增益、整体方法超过原A1、Damaged已改善、分区没有任何问题、Memory会恢复性能。10个验证点不是10次独立种子实验。

下一步不必先改Transformer或延长到50000步。先保留原图内容，并读取各类IoU/F1及混淆矩阵，确认恢复来自哪些类别。

## 新增ROI约束实验与当前实验的区别

实验代码目录：bda_benchmark/experiments/damageformer_roi_partition_control_v1。

| ID | 新增变化 | 问题 |
|---|---|---|
| s0 | 原Q、固定roi内容 | 同协议参照 |
| s1 | 根据位置与区域建筑概率差对Q重加权 | 相同K下柔性约束是否有效 |
| s2 | 每个区域拆成预测建筑与背景两组 | 直接隔离汇总是否有效 |
| c2 | 与建筑无关的固定空间二分 | 是否只是分得更细 |

四组仍冻结前端和Q生成网络；s1/s2/c2对归属做确定性改造，不称为训练生成器。全部共用roi特征，因此有效性应先比较各组与s0；当前raw仍是重要参考，不能预设roi是最佳。

s2/c2最多2K槽位，实际占用数可能不同。不能只看分数而不报告区域数。该独立目录已在本地通过8项CPU测试；截至用户最新附件，尚未提供服务器实验结果。
