# DFC2025 建筑先验对当前 SRAC 超像素与 Memory 的迁移分析

日期：2026-10-11。依据：用户提供的 Val450/Test878 结果、本地当前实现、冠军原论文与两队作者代码。此次是文献和代码分析，未运行新训练、未改变现有实验。

## 研究问题与结论

任务是灾前光学与灾后 SAR 的四类损毁分割；目标是改善当前区域表示和 Train-only Memory，尤其减少真实 Intact 被检索证据误导为 Damaged。不训练“何时采纳/拒绝”的门控。

建议将建筑先验作用拆为三层：建筑/背景分离、损毁类别边界保护、逐栋实例范围。当前实现已有第一层的软约束，第三层并不存在；不能把三层都称作“建筑约束”。先保留已有效的 Q 对照，在独立分支验证建筑加权聚合、显式区域监督，最后才考虑实例限定。

## 文献核实与实验口径

1. 武汉大学冠军论文《Building-Guided Pseudo-Label Learning for Cross-Modal Building Damage Mapping》为 IGARSS 2025。其 II-B 将官方有标注数据按 80/20 划分训练建筑提取器；不能由此推断使用了额外建筑数据集。作者仓库有 BuildingExtraction、ChangeDetection 两阶段。
2. 冠军论文还明确生成测试图像伪标签并继续训练。这属于使用目标域未标注图像的适配，与当前只在 Train 训练、冻结后测试的方案不同。迁移建筑先验机制时，不默认迁移该数据使用协议。
3. 冠军 Table I 的 mIoU 包含 Background；测试四类 IoU 为 97.995、67.304、9.748、42.086，四类平均 54.283%，三前景类平均约 39.713%（本文由表中数值计算）。用户当前报告是三前景类平均。数据划分、集成和适配也不同，不据此比较优劣。
4. 北京师范大学方案为 IGARSS 2025《Building Damage Mapping through Heterogeneous Feature Consistency and Knowledge Integration》。作者代码确认定位与损毁分支融合、Intact 高层跨模态 MSE，并有使用测试图像进行伪标签微调的脚本。竞赛结果综述 VI-B 描述 xBD 定位先验补漏、伪标签微调和对象投票。此次未完整验证后处理流水线，不能把 50.81% 归因于单独的 xBD 或对象投票。
5. 论文方法与公开实现并非逐项完全一致：BNU 综述的特征约束公式掩膜与公开 DFv4 实际选择有差别，本报告的代码结论以 DFv4 的 `post_label == 1` 为准。

来源：[冠军论文](https://arxiv.org/html/2505.04941v1)、[冠军作者代码](https://github.com/Henryjiepanli/Building-Guided-Pseudo-Label-Learning-for-Cross-Modal-Building-Damage-Mapping)、[BNU 会议页面](https://www.2025.ieeeigarss.org/view_paper.php?PaperNum=6399&SessionID=1631)、[BNU 作者代码](https://github.com/zxqyiyang/DF2025)、[竞赛结果综述 DOI](https://doi.org/10.1109/JSTARS.2026.3697217)。

## 当前实现已经有什么

| 部分 | 代码事实 | 对设计的影响 |
|---|---|---|
| 原 A1 定位 | `DamageFormer_S8_MICB_DSMIL.py:597`，灾前光学 `clf_1` 输出 `p_building` | 已经有建筑定位器；是否曾用外部数据预训练须追溯实际 checkpoint manifest |
| 原 A1 特征调制 | 同文件约 600 行，`alpha + (1-alpha)*p_building` 乘融合特征 | 已经在突出建筑，同时保留非零背景上下文 |
| Q 建筑先验 | `srac_transformer_v1/model.py:124–147` | 建筑概率与区域中心建筑概率相容时更易分入该区域 |
| Q 空间限制 | 同文件约 82–155 行 | 3×3 邻近种子、迭代更新；默认 stride=8 是特征格单位，不是原图 8 像素 |
| 结构注入 | 同文件约 184–194 行 | 建筑概率、Q 边界、Q 归属熵输入 adapter；这不是额外边界监督 |
| 当前前端训练 | `train_front.py:188–189` | 回投概率 NLL + Lovasz；Q 受任务间接监督，没有单独的建筑/语义重建或边界损失 |
| Memory 特征 | `model.py:285–301` | 主特征按 Q×学习空间权重汇总，另有原 Q 的均值/标准差和几何 |
| Memory 标签 | `common.py:160–171` | 按 Q 汇总 Train 真值四类比例；与主特征的权重并非完全一样 |

Q 的建筑相容项是 `log(b_i*b_r + (1-b_i)*(1-b_r))` 乘固定系数。它能偏向“建筑跟建筑聚、背景跟背景聚”，但两栋相邻楼的 b 都接近 1，即使一栋 Intact、一栋 Damaged，也无法凭这个项分开。

其他旧分支 `damageformer_a1_cross_modal_superpixel_v1/losses.py` 已有建筑重建和边界相容损失；当前 SRAC 未使用，不应将其当成全仓库从未有过的创新或已验证收益。

## 哪些机制可以迁移

| 机制 | 匹配程度/成本 | 可落地改动 | 必须保留的边界 |
|---|---|---|---|
| 灾前建筑定位先验 | 同任务，低到中 | 先评估已有定位头的召回/边界，再决定是否用 BRIGHT Train 单独适配定位 | 定位好不等于损毁等级分得好；建筑范围应包括后来毁坏的位置 |
| 建筑图调制特征 | 已有同类机制 | 检查它是否进一步进入一致的区域聚合权重 | 不能将“首次乘建筑图”包装成新增贡献 |
| 完好区跨模态一致性 | 同任务，中 | 在检索投影的小分支上用 Train Intact 构造受限一致性对照 | 不把全部 Damaged/Destroyed 特征强制拉到相同，否则可能抹掉损毁差异；不直接对未对齐原始 RGB/SAR 特征求差 |
| 可靠伪标签训练 | 数据条件不同，中到高 | 仅在单独声明的半监督/目标域适配协议中使用 | 当前 Train 有真值，Memory 标签优先使用真值，不用模型预测替换；Test 伪标签训练要单列 |
| 对象级投票 | 依赖定位与实例质量，中 | 先测候选建筑合并/分裂率，才研究同栋约束 | 二值连通域不是可靠建筑实例；一栋误分会整栋传播 |

0.3 是冠军方法的特定归一化熵阈值，不能直接用于 Q 的九候选归属熵或四类损毁熵。低熵不等于正确；建筑定位置信度高也不代表 Memory 损毁标签单一。

## 推荐的 Memory 建立方式

### 第一版：固定 Q，先检验建筑加权的区域描述

对一张图，B_i 为同一冻结定位器预测的建筑概率，Q_ir 为像素/特征位置 i 属于区域 r 的权重。定义聚合权重：

`W_ir = Q_ir * B_i`。

以同一个 W 计算区域特征和 Train 四类标签分布：

`f_r = sum_i W_ir F_i / sum_i W_ir`

`y_r(c) = sum_i W_ir 1[Y_i=c] / sum_i W_ir`。

实际实现需对齐分辨率、正确屏蔽 ignore=255、处理零有效质量。以上公式用于有效标签位置；不能让无效位置只进入一侧分母。为避免改变描述维度、Reader 容量等额外变量，先建立独立且等规格的均值描述对照。

这是“当前区域中更关注建筑部分”，不是新 Q，也不是实例分割。特别是逐像素对 r 归一化 `Q_ir*B_i` 时，公共 B_i 会约去，不能宣称那样修改了像素归属。

背景条目应作为显式对照保留，不能把整个四类 Memory 一刀切为建筑库。新实验维持旧事件×类别配额和总容量，记录建筑覆盖、三前景类混合程度、有效质量、来源和选样退让。两种纯度要分别记录：背景少，不代表 Intact/Damaged/Destroyed 不混合。

Train 与推理都使用预测 B 和同一特征抽取规则。Train 真值用于条目标签和质量统计；Val/Test 真值不参与区域形成、建库、邻居排序。若担心训练集上定位过于乐观，可另用 Train 内交叉预测，明确这是新增实验条件。

### 第二版：需要分栋时，记录“候选建筑里的局部区域”

只有诊断显示一块 Q 经常跨越不同建筑类别、且预测实例质量足够时，增加候选实例掩膜 M_ib：

`W_irb = Q_ir * M_ib`。

条目单位变成“第 b 栋候选建筑内的第 r 个局部块”；一栋楼允许多个局部块。支持与查询都同样构造。模型仍需区分同一楼内不同局部的有效信息，而不是用一个整栋平均向量替换所有局部特征。

已有 `building_context_v2/building_ops.py` 是建筑概率阈值加连通域，可做候选，不保证能分开接触建筑。不将其直接叫真值建筑实例。

### 检索与回投

检索的内容应包含能够区分损毁的双时相表示，不是只比较建筑外形或灾前 RGB 外观。首先在相同容量、同一支持成员下比较描述；再单独训练 Intact↔Damaged 困难负例投影。不能按查询当前预测类别只检索同类，避免把现有漏判锁死。

检索结果先仍作为区域上下文回投，与像素特征共同分类。对于实例交集版本，只按对应的 Q×M 曝露范围分配上下文；不把一个历史 Damaged 标签直接涂满整栋楼。保留像素模型能处理的未覆盖位置，不增加采纳/拒绝门控训练。

改变 token 聚合规则或 Q 后，必须重抽 Train 支持和查询，并检查投影/Reader 的适配。旧 Reader 冻结实验只说明它能否即插即用，不等价于新表示的最终可达性能。若训练下游适配，旧新表示两边用同预算、同结构对照，不能混入额外训练收益。

## Q 是否应该重新控制

应该针对已量出的错误设置约束，而不是立即增加建筑权重或强迫一个超像素等于一栋楼。

| 已确认的错误类型 | 合适的控制 | 不能由此解决的内容 |
|---|---|---|
| 建筑与道路/背景混合 | 改善 B；同 Q 建筑加权聚合；二值建筑重建监督 | 相邻不同损毁楼的区分 |
| 跨 Intact/Damaged/Destroyed 边界混合 | Train 四类标签的区域汇总—回投重建监督；必要时细化局部尺度 | 同类相邻楼的实例编号 |
| 明确需要逐栋范围 | 预测实例/边界与 Q 相交 | 定位漏检、合并实例自身的错误 |
| 纯区域仍检索错类 | 改描述与度量学习、困难负例 | 不应指望只改 Q 解决 |

语义重建监督可借鉴 SSN/SpixelFCN：把 Train 标签经 Q 汇总再回投，鼓励不要跨类别传播，并配空间紧凑约束。真实标签只出现在训练损失，不输入推理分区。当前 SRAC 没有此独立损失，但已有最终任务监督；需要比较新增损失是否确实改善下游表现。

边界监督须对齐真实 seed ID，不能把稀疏 Q 的九个相对候选槽当作全局同名区域。Q 边界图只是不同归属概率；其存在不等于已经有 GT 边界损失。

不以“区域越纯越好”为唯一目标：细到单像素当然纯，却失去共享收益和计算优势。比较时同时报告区域数、有效支持质量、小建筑覆盖、背景稀释、前景类混合、边界误差、最终四类 IoU。

## 最小实验次序

1. 保持已启动/准备启动的固定 F/Q 的 P/R/T 适配实验不变。它回答区域表示与头适配问题，不能中途替换 Q。
2. 只读测已有 B 的建筑召回与边界误差，以及 Q 的两种混合度。将 Intact→Damaged 错误按这些量分层；不要把原来全部来自 Intact 的假阳性都归给跨建筑混合。
3. 固定 Q、支持成员、容量、投影/读取配置，比较普通均值描述与建筑加权且特征/标签一致的描述。先测标签相容性、困难查询 Top-8/64 覆盖，再看固定 Reader 的输出。
4. 只有诊断支持时，在新分支增加 Q 建筑或四类重建监督。做“旧 Q/新 Q × 无 Memory/有 Memory”四组，分别重建匹配库；两边相同前端训练预算、库容量及下游训练预算。
5. 外部数据预训练、实例切分、多尺度和跨模态投影一致性分别作为后续独立变量，不同时加入。

结构选择用 Train/Val 完成；固定外部数据清单，检查与评估事件/地理范围重叠。竞赛有目标域自训练，不代表当前协议自动授权相同数据使用方式。

## 三个可执行研究题目候选

1. **面向光学—SAR 建筑损毁检索的建筑范围内区域描述与标签对齐**。固定 Q，对比统一 W 下的特征/软标签与旧聚合；在 BRIGHT Train/Val 测困难 Intact/Damaged 检索和误改。贡献需来自定量证明的错位及修复，而非简单乘掩膜。成本中。
2. **任务监督的软区域划分对跨事件损毁 Memory 的影响**。用 Train 四类重建损失训练 Q，在相同容量下做 Q×Memory 因子实验。贡献是区分图内共享收益与跨图检索收益；不是再宣称可微超像素本身新颖。成本中到高。
3. **预测建筑候选内多局部原型的跨事件损毁检索**。预测候选与 Q 相交，比较整区、整栋和栋内多局部条目，显式分析实例合并/分裂。需足够好的候选范围；成本高，放在证据支持之后。
