# BRIGHT 的超像素生成学习与 SAR 信息使用方案

分析日期：2026年10月6日。

研究对象是 BRIGHT 灾前 RGB 与灾后 SAR 四类建筑损毁分割。建议先固定原图融合与 Soft ROI 内容、建筑分组规则和完整区域读出，区分三个问题：生成器是否需要继续适配；SAR 是否应该影响区域归属；SAR 是否更适合只决定区域读取哪些内容。以下是三个独立实验方向，不是需要一次全部拼接的模型。

## 当前实现与研究边界

本地镜像中的实现为：

1. 灾前 RGB 的冻结 Swin 多尺度特征进入轻量嵌套解码器。
2. 解码器输出描述子，在特征图 stride8 的种子网格上，对附近九个中心计算归属，进行三轮中心更新。
3. 原始 Q 是 RGB 描述子相似度与空间距离的函数。V2 调用聚类时传入全零建筑图，建筑分组在后续路由中完成。
4. 区域内容来自原图 RGB 与 SAR 融合后的 Soft ROI 特征。SAR 已经参与损毁分类，但没有直接进入当前 Q 生成器。
5. 注意力 Pooling、mean/std 旁路、区域分类器和概率回投已经存在；不能将再次加入这些模块作为新改进。
6. followup 的 `fixed_q` 与 `learn_q` 分别固定原 Q、更新其复制的 RGB 解码器。两组完整读出均训练。Swin、内容特征、建筑概率 B 和前端缓冲区冻结。
7. 该处 `hard` 指建筑与背景组之间不交换，不等于把九候选 Q 全部 argmax 硬化。Q 内部仍可为软归属。

## 生成与使用的区分

生成回答位置 i 应分配多少权重给区域 k，记为 Q。使用回答区域应从哪些位置读取什么证据，以及区域结果回写哪些位置。

普通区域分类将二者绑定：同一个 Q 既收集内容，又回投类别。这种做法能抑制局部波动，也可能混入其他建筑或背景。一栋楼可由几个区域提供互补观察，不要求每个区域等于一栋楼，更不要求它们代表不同损毁等级。

SAR 应被考虑，但不必一开始就控制输出边界。侧视几何会使建筑散射支持范围偏离光学轮廓；亮暗、斑点或模态特征差异都不能直接解释为损毁程度。[QuickQuakeBuildings 的配准及取块设计](https://arxiv.org/html/2312.06587v2)

## 方案一 RGB 结构分区的任务适配

建议题目：面向 BRIGHT 的建筑结构监督超像素适配。

研究假设：现有 RGB 描述子没有针对当前可靠内容与读出充分适配；改善学习目标比换生成器更值得优先验证。迁移成本低，机制本身已有文献依据，新贡献要来自任务适配及可靠实验。

### 最小对照

| 组别 | 更新分区解码器 | 更新完整读出 | 分区辅助损失 |
|---|---|---|---|
| U0 | 否 | 是 | 无 |
| U1 | 是 | 是 | 无，仅现有区域 NLL 与 Lovasz |
| U2 | 是 | 是 | U1 加二值建筑标签重建 |

实际命名建议使用 `fixed_q`、`learn_q`、`learn_q_structure`，不要与历史 DamageFormer A1 权重混淆。

先读取或完成已有 `fixed_q` 对 `learn_q`，不重复启动同一实验。若增加 U2，必须保留相同的 U1 对照，不能同时增加新紧致度损失、SAR 输入或新的分类头。所有组沿用当前空间距离惩罚，而不是假称现有实现已有独立紧致度损失。

### 结构重建怎样监督 Q

设训练集有效位置的二值建筑标签为 y_i，原始、未建筑分组的 Q 每行和为 1。区域内先汇总标签，再按 Q 还原：

    mass[k] = sum_i Q[i,k]
    region_label[k] = sum_i Q[i,k] * y[i] / mass[k]
    reconstructed[i] = sum_k Q[i,k] * region_label[k]
    structure_loss = BCE(reconstructed, y)

空质量区域必须屏蔽，不参与反投影；实现以稀疏九邻居 scatter/gather 完成，不构建 N×K 稠密矩阵。GT 只进入训练损失，不进入预测 Q、建筑概率 B、区域分类器输入或推理。

直观含义：如果一个区域过度混合建筑与背景，还原后的建筑轮廓就不准；损失会更新 RGB 描述子，使两侧更不愿共享区域。没有预先规定唯一正确的超像素编号。

该项应作用于硬 B 拆分之前的原始 Q。否则结构监督与已有建筑分组纠缠，不能清楚评价生成器本身。若标签需要降到特征网格，先将有效类别转为前景指示及有效掩膜，再做面积覆盖率汇总；不对类别编号做双线性插值。只在有效覆盖上归一化，并保留原分辨率最终评价。

限制：二值标签无法区分相邻同类建筑；也不能教仅看灾前 RGB 的分区器识别灾后裂缝。它不会修复冻结 B 的整栋漏检，尤其无法重新打开硬分组置零的跨组路由。只让分区更纯而损毁指标不升，不算任务改进。

停止条件：相同预算、多种子下，U1/U2 不提高最终分割，或以小建筑召回、定位错误位置为显著代价，则停止继续加分区辅助损失。不要转而将轮廓整齐当作成功。

## 方案二 RGB 主导的双模态区域相似度

建议题目：面向 RGB–SAR 建筑损毁评估的模态内一致性引导分区。

研究假设：灾前 RGB 可约束空间结构，但部分不适合共同分类的位置只能由灾后 SAR 证据区分。使用两模态各自的区域相似度可能改善归属。迁移成本中等，属于待验证的组合假设，不是已发表论文对本数据的结论。

### 生成方式

复用冻结的两个 Swin，不增加第三主干。分别把 RGB 与 SAR 特征投影为同网格、独立归一化的描述子 r_i、s_i。以同一组有序种子和当前 Q，分别更新两个模态的区域中心 cR_k、cS_k：

    score[i,k] = (1-beta) * cosine(r[i], cR[k])
                 + beta * cosine(s[i], cS[k])
                 - spatial_weight * squared_distance(x[i], center_xy[k])
    Q[i,:] = masked_softmax(score[i,:] / temperature)

保留九候选、三轮、同分辨率及种子预算。RGB 只与 RGB 区域中心比较；SAR 只与 SAR 区域中心比较。没有 RGB 减 SAR 的所谓真实变化量。beta 首轮使用预先固定的小权重；若以后引入学习门控，要作为下一项独立变化，不能将任意 sigmoid 权重称为校准好的可靠性。

### 公平对照

仅比较单 RGB 解码器与多一个 SAR 适配器，无法排除额外容量。至少补相同双分支结构的 `RGB+RGB` 和 `RGB+SAR`，投影宽度、中心更新、读出、初始化规则与有效训练预算一致。原有单 RGB 方法保留为参考。

区域使用方式仍是既有建筑分组、完整区域表示、分类、原 Q 回投，不同时改变 Soft ROI 或交换规则。训练用相同原损毁目标；不要在这一对照中额外加入方案一的结构损失。

额外诊断：只给进入生成器的 SAR 描述子做预设小幅平移，区域内容输入保持不变，观察 Q 与输出变化。这个人为扰动检验分区对错位的敏感性，不是测得真实配准误差，更不是训练增益证据。

风险：同坐标的 SAR 可能对应别处的散射体；强散斑与灾害事件纹理可能主导 Q。归一化后的深层特征也不自动等于去斑特征。BRIGHT 使用单极化且经显示尺度处理的数据，不应直接套用需要极化协方差的 Wishart 距离，也不应对已归一化 Swin 特征假设原始 SAR 幅度分布。

停止条件：在相同容量下没有超过 RGB+RGB，或碎片、小对象伤害及跨事件波动明显增大，则 SAR 不进入输出分区，保留它在内容分支的作用。

## 方案三 固定输出分区的 SAR 引导内容读取

建议题目：面向建筑定位误差的超像素输出与跨组取证分离。

这是生成器实验没有明确收益、且汇总与回投审计支持读取瓶颈后才考虑的使用方式改动，不与方案二一起训练。迁移成本中等；完整几何偏移版本成本更高。

### 两张表分工

- Q_out：固定当前 RGB 分区与建筑分组，规定区域类别回写哪些位置。
- W_pool：规定区域从哪些位置取得特征。初始版本只在现有局部候选与有序 2K 槽位内，按 SAR 模态内相似度分配有限交换权重。

原图融合 Soft ROI 内容 F 不变：

    token = existing_region_embedding(F, W_pool)
    region_probability = softmax(existing_classifier(token))
    prediction = unpool(region_probability, Q_out)

### 最小三组

1. HH：不交换汇总，不交换回投。
2. EH-uniform：原有限均匀交换汇总，硬回投。
3. EH-SAR：相同交换质量预算，由 SAR 相似度决定交换给哪些已有候选，仍硬回投。

先用已有 HH/EH/HE/EE 审计确定是否值得进入本实验。既有 hard 与 exchange 的近乎持平结果，不能当作此方案已经成功。

一种不增加新门控的实现是：自身预测组的九候选沿用 (1-epsilon)Q；另一组保留总量 epsilon，但按相应 SAR 区域相似度重新分配。SAR 中心来自固定参考路由，尺度归一化。对不存在的对侧非空候选，显式退回自身组并统计回退率；两交换对照采用相同候选掩膜和回退策略。比较时报告实际交换量，而不只报告 epsilon。

注意力主路与 mean/std 旁路都使用同一 W_pool，回投使用 Q_out；两表必须共用相同有序槽位。屏蔽空汇总槽位后在原特征网格上重新归一化回投，不能让空 Token 的偏置被读回图像。

这个版本只验证局部候选内的内容选择，不是物理 SAR 叠掩校正。若后续希望读取更远的 SAR 特征或学习偏移，必须另设等范围均匀采样对照，并在融合前的 SAR 特征上实现；已经混合好的 RGB–SAR 内容无法被描述为只移动了 SAR。没有观测方向、建筑高度等条件时，不能把学到的偏移解释为真实建筑几何。

停止条件：仅提高总体精度但再次损害 ROI 漏检建筑、小对象或某个等级，或相同预算下不优于均匀交换，则不增加更复杂的可变形模块。

## 直接预测归属和对象内播种何时考虑

SpixelFCN 的直接九通道归属可替换三轮中心迭代，但应作为与上述三个方向分开的架构对照：同输入、同分辨率、同种子数量、同监督、同读出，比较迭代与直接预测，并报告参数和耗时。它可能更快，不意味着一定更适合 BRIGHT。

SPAM 式对象内播种应在小对象被漏分、建筑区域预算不足的证据下考虑。保留全图基础覆盖，在同一总预算内向预测建筑或不确定带重新分配种子；不要删除低 B 区域，也不要同时增加总种子数。不规则播种要重建候选索引，不能继续用规则网格位置公式。连通性后处理要单独开关，所有对照一致应用，并记录实际区域数变化。

## 张量与梯度约定

用 n 表示 batch，h×w 表示分区网格，N=hw，K=ceil(h/8)ceil(w/8)：

- 原始局部 Q：`[n, 9, N]`，候选 ID 同形或 `[9,N]`，沿九候选归一化。
- B：`[n,1,h,w]`，来自冻结预测。
- 当前分组后路由：`[n,18,N]`，有序槽位为 `2*k+group`，上限 2K；hard 下每位置仅其中九项可非零。
- 现有内容通常为 `[n,256,h,w]`，Token 为 `[n,2K,128]`，区域概率为 `[n,2K,4]`；实现需按实际捕获张量断言。
- 确保 invalid 候选、严格空中心和超出边界的位置被屏蔽，任一位置至少有一个有效候选。
- 计算质量和平方统计使用 FP32；极小质量与严格空质量分开记录。不要无声丢弃小建筑 Token。
- 不对 GT 类别编号插值。原图与特征图使用一致 resize 约定；若 align_corners=False，特征中心 u 对应原图中心坐标 `(u+0.5)*W/w-0.5`。种子 stride8 不能直接称为原图八像素。
- 学 Q 时：损失→概率回投→Q 与 Token→Pooling→Q→中心更新→描述子解码器。聚类循环不能处于 no_grad，也不能在训练路径对 Q 使用 argmax。
- 冻结内容不阻止 Q 学习；但冻结 B 的阈值决策不接收梯度，既有硬零支持也不会因训练解码器自行恢复。

## 评价与决策

所有组使用 Train2918 与 Val450，固定前端哈希、读出结构、数据次序、batch×累积、优化器步数及验证规则。优先比较相同步数终点；最佳检查点作为另列结果。当前快照与历史 A1 的训练经历不同，历史分数仅为参考。

分类效果与分区质量分开报告：

- 分类：全图前景 mIoU，三类 IoU，Damaged P/R/F1，Damaged→Intact 与 Damaged→Destroyed 的伤害和反向救回，背景误报。
- 条件错误：B 的假阴性、假阳性及置信度分箱；前景侧与背景侧边界；内部；小对象代理；每事件及类别支持数量。
- 分区：软/硬实际区域数、空与极小质量组、归属熵、硬化后的碎片率，建筑与背景分别计算的混合程度。不能以背景主导的全图纯度代表建筑分区质量。
- 成本：相同分辨率、batch、设备下的峰值显存和前向耗时，并注明是否包含前端与三轮迭代。
- 可靠性：先做小预算排错，出现正向信号再做至少三个配对种子。训练种子标准差与按图像/空间块分组的配对重采样不确定性分开报告；不把数亿相关像素当独立样本。ASA 不是前景 mIoU 上限。

采用顺序为：先完成现有固定与学习 Q 比较，再单独验证结构监督；有必要时才测试双模态分区。若区域生成改动无益且证据指向读取错误，再转向固定输出 Q 的内容支持实验。Memory 只在固定 Embedding 上与同容量无 Memory 分支比较，不与 Q 适配同轮变化。

## 创新边界

可微聚类、直接归属、标签重建、对象先验、可变形采样均有已有工作。任务适配是把建筑级监督、光学输出位置与 SAR 证据范围分清，再围绕当前 ROI 定位错误设计可证伪对照。尚待验证的是模态内一致性是否比 RGB 单独分区更好，以及 SAR 选择的有限交换是否优于同预算均匀交换。组合模块、引入一个 beta 或获得更整齐的可视化，都不能单独证明原创性或分类提升。
