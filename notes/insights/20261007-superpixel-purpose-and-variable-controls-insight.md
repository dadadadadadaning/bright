# BRIGHT超像素的作用与变量控制

记录日期：2026年10月7日。任务是灾前RGB与灾后SAR的建筑等级分割，Train2918、Val450。本文依据已有实验记录、当前本地实现及原始论文，说明哪些因素已经验证、哪些仍是假设。没有修改实验代码、启动训练或读取Test图像与标签。

当前结论不是“超像素无效”，而是“现有学习Q及建筑分组在区域方案内部有效，但尚未证明能够可靠超过像素主线”。下一步应控制变量，不能把更漂亮的分区、更多迭代或接入Memory当成必然提升。

## 超像素究竟增加什么

超像素重新组织已有观测，不增加一张新的灾后图像。对本任务，可以检验三种作用：把兼容位置的证据汇集起来；减少不同对象或背景之间的不当混合；将密集特征压缩为可供上下文处理和历史检索的区域Token。代价是压缩和错误分组可能丢失判别信息。

BRIGHT按建筑多边形赋损毁属性，并非对同一栋楼的每个局部独立标注损坏等级。因此，一栋建筑划为多个超像素可以是收集不同观测证据，但不能解释成发现多个有GT支持的局部损毁等级。GT连通域也不等于真实建筑实例。[BRIGHT论文第2.2节](https://essd.copernicus.org/articles/17/6217/2025/essd-17-6217-2025.html#section2)

区域更一致不等于类别更准确。若几个位置共同被错判，输出可以更整齐而mIoU更低。压缩Token也不自动意味着整个系统更快：当前仍运行Swin与新增分区解码器，必须测量端到端时间和显存。

## 目前三个阶段的关系

```text
生成Q：RGB结构特征 → 分区描述 → 局部中心更新 → 位置对区域的软归属
使用Q：原图融合特征＋Soft ROI → 按预测建筑标签拆组 → 区域汇总与分类 → 回投
Memory：固定上述表示 → 检索Train历史区域 → 学习区域分类修正
```

这里hard指建筑与背景的硬分组，组内依然使用软Q；不是将Q整体argmax。Memory不是生成超像素的必要组件。新的Memory对照固定Q和Embedding，因此不会自动改善分区，也不能用其结果单独证明超像素优于无超像素。

当前来源是A1初始化后区域联合训练3000步的前端快照，以及后续训练的hard读出，不是原始A1。历史A1的61.6866%与快照old_pixel的60.8998%不能当作同一冻结权重的两个结果。

## 已有证据与未解决的问题

| 对照 | 已观察结果 | 可支持的范围 |
|---|---|---|
| 同Q、同完整读出的内容对照 | 最佳raw61.3973%、roi61.3325%、normal59.6111% | 当前图像调制路径较弱，不能推广为所有调制无效或Soft ROI无用 |
| 网格与学习Q加建筑分组 | 最终G1为60.7229%、S2为61.5216% | 当前软Q方案优于当前硬网格，形状、软硬和实际区域数仍混杂 |
| 同学习Q是否建筑分组 | 最终S0为61.1712%、S2为61.5216% | 建筑分组有单次训练增益；主要减少背景误报，也伤害定位错误处 |
| Q继续学习及二值结构损失 | 最终fixed为61.5458%、learn为61.4588%、learn+structure为61.4601% | Q有更新不等于分类改善；不是所有任务监督分区的否定 |
| SAR参与分区 | 最终匹配RGB对照61.4623%、SAR61.4638% | 当前固定权重混合相似度无明确增量，不等于SAR无用 |
| SAR跨组支持 | 最终hard61.5457%、普通交换61.5561%、SAR交换61.5557% | 纠错与伤害抵消，SAR选择未超过普通交换 |

表内只在各自实验内比较，不将不同实验的best与final混为一个排名。十次验证是同一条训练轨迹，不是十个独立种子。

当前至少存在四个竞争解释：区域粒度不合适；建筑预测错误被硬分组放大；汇总后的表示或分类器适配不足；Swin已有上下文使新增聚合收益有限。前两者也可能共存。没有证据将全部差距归因于某一个参数。

## 代码中实际的生成方式

本轮核对的V2前端复用RGB Swin多尺度特征，轻量嵌套解码器产生32通道分区描述。区域Token默认128维，两者不能混淆。每个位置只比较固定的九个邻近种子候选。

当前局部相似度可写为：

```text
score(x,k) = [cos(e(x), center(k)) − 0.1 × ||xy(x)/s − center_xy(k)||²] / 0.2
Q(x,k) = softmax_over_valid_candidates(score(x,k))
s = 8；重复中心更新与归属计算3轮。
```

中心位置在同样的归一化坐标中计算。空中心及无效边界候选被屏蔽；每位置的Q和为1。增加轮数不会增加候选中心数量，也不是扩大RGB与SAR之间的配准搜索范围。

V2调用聚类函数时传入全零building，所以原始Q生成阶段没有建筑硬隔离。S2在之后将区域索引改为`2*region_id + predicted_building_group`，Q数值不变，建筑与背景分别汇总。它不是逐栋建筑实例分割。

主路径按Q乘注意力权重进行加权汇总，并除以该区域权重总质量；mean/std旁路按Q统计。分类后回投使用同一路由的Q混合区域概率，接着上采样到原图。空间注意力并不等于强制排除背景，mean/std也不能完整恢复原像素布局。

## 可变因素清单

| 因素 | 当前值或状态 | 改变的实际含义 | 应固定的比较条件 |
|---|---|---|---|
| 原图到特征图的下采样 | 当前Swin路径为约4倍 | 分区能直接处理的空间采样分辨率 | 种子物理间距、内容分辨率、读出结构 |
| 种子间距s | 特征图8格 | 目标区域数、名义粒度、局部候选覆盖范围一起变化 | 特征分辨率、温度、空间权重、B、训练预算 |
| 每位置候选数 | 邻近3×3，共9个 | 能参考的区域中心范围 | 不能同时改变SAR对齐机制 |
| 聚类迭代次数T | 3 | 一次前向内中心和归属更新次数 | 同一描述网络、初始种子、候选图和读出 |
| 归属温度tau | 0.2 | 小值通常使归属更尖锐，大值通常更分散 | 空间权重、特征归一化与区域数量 |
| 空间权重lambda | 0.1 | 位置近邻与内容相似性的相对偏好 | 温度、坐标单位、种子间距 |
| 分区输入 | 原RGB；实验二另有SAR描述 | 用什么证据决定哪些位置兼容 | 分类内容始终包含RGB与SAR |
| 分区描述维度 | 32 | 相似度表示容量 | 不与区域Token维度128混淆 |
| B分组规则 | 阈值0.5，建筑/背景拆组 | 改变汇总和回投的允许关系 | B本身冻结，四类输出不能被组名强制限制 |
| Q是否继续训练 | 主参照冻结 | 损毁损失是否调整分区解码器 | Swin、B、内容及其他损失不变 |
| 额外分区损失 | 已测试0.1二值结构重建 | 鼓励建筑/背景结构，不直接区分三个损毁等级 | 不同时增加类别权重或Memory |
| 区域表示和分类器 | 注意力Pooling、mean/std、128维Token | 如何压缩及解释区域内容 | 比较生成器时完全相同 |
| 汇总与回投关系 | hard分组，两端匹配 | 谁提供内容与谁读取结果 | 改一端必须记录另一端及空槽回退 |
| 连通性处理 | 无保证、无后处理 | 是否拆开或合并断开的硬区域 | 实际区域数、合并规则及读出重新适配 |
| 优化与采样 | 配对5000更新、有效batch16等 | 学习进度与样本组成 | 同初始化规则、同裁剪序列、同Val选择规则 |

温度和空间权重耦合，其他论文的数值不能直接照抄。上述变量不是全部都有命令行开关。V2训练入口开放dim和stride，但未开放聚类temperature、spatial_weight、iterations或decoder宽度；当前冻结读出实验继承checkpoint配置。实验三的support_temperature是跨组支持分配的温度，不是原始Q的温度。只设置同名环境变量不意味着模型会采用它。

## 区域尺度要怎样对应BRIGHT

正常整除输入下，本地V2的Q位于H/4×W/4，名义种子间距是`4*s`个原图像素。当前s=8对应32像素，而不是8像素。它不表示每个最终超像素都是32×32方格。

| 原图大小 | Q网格 | s=8种子数 | 建筑拆组后的分配上限 |
|---|---|---:|---:|
| 512×512训练裁剪 | 128×128 | 256 | 512 |
| 1024×1024图像 | 256×256 | 1024 | 2048 |

验证代码保留原图尺寸，不强制resize到1024；表中1024是对应标准图像大小的计算。应在实际运行时记录输入及Q形状。名义区域数是`ceil(h/s)*ceil(w/s)`，实际软占用、硬占用和极小质量区域数必须另报。

BRIGHT原论文报告GSD为0.3至1米，且建筑尺度存在差异。因此，如果文件没有额外重采样，32像素对应的地面间距可以约为9.6至32米。这是尺度换算，不是建筑大小，也不是区域真实面积。[BRIGHT论文第2节及Table 2](https://essd.copernicus.org/articles/17/6217/2025/essd-17-6217-2025.html#T2)

设置尺度之前，优先在Train统计对象代理的面积和短边像素数、下采样后的覆盖、每对象涉及的有效区域数，以及每区域覆盖多个不同GT等级的比例。用实际元数据核实GSD；不能凭事件名称臆造分辨率。GT只用于Train统计或离线诊断，不参与实际分区。

同一对象可以需要多个Token，却未必需要多个类别；目标是保留判别证据。建筑已经小到只有一两个特征位置时，加密种子不能恢复下采样前已经不可区分的细节。反过来，区域过碎会产生低质量Token，尤其现有hard拆组已经产生不少微小质量槽位，不能默认越细越好。

RGB与SAR的成像差异和残余配准问题，意味着不能把强光学轮廓当作SAR证据必须落在其内的保证。保留原图和Soft ROI，不额外裁掉预测建筑外的输入；若研究扩大支持域，必须单独验证接收区域的异组占比，而不是只限制每个发送位置的5%。周边支持有益仍是待验证假设。

## 文献能够提供哪些机制

以下是定向检索，不是“所有超像素论文”的穷尽综述。没有一项可以直接证明当前RGB与SAR模型必然提升。

| 原始工作与代码 | 原任务及监督 | 可迁移部分 | 迁移风险与难度 |
|---|---|---|---|
| SLIC，TPAMI 2012；[作者论文与代码页](https://www.epfl.ch/labs/ivrl/research/slic-superpixels/) | 自然图像颜色与坐标聚类，无任务训练 | 将数量、紧致度和边界贴合作为不同变量；传统只读对照 | 颜色相似不等于建筑损毁相同；低成本诊断，不是直接替代目标模型 |
| SSN，ECCV 2018；[论文](https://arxiv.org/abs/1807.10174)、[官方代码](https://github.com/NVlabs/ssn_superpixels) | 图像分割及光流等任务的可微聚类，任务相关监督 | 学习分区描述、软关联与中心更新；当前方法所属思路 | 官方为Caffe且有连通性处理；现有PyTorch改编不等于原版。迁移低至中 |
| SpixelFCN，CVPR 2020；[论文](https://openaccess.thecvf.com/content_CVPR_2020/html/Yang_Superpixel_Segmentation_With_Fully_Convolutional_Networks_CVPR_2020_paper.html)、[官方代码](https://github.com/fuy34/superpixel_fcn) | RGB超像素及双目视差；分区监督与下游任务训练 | 直接预测局部归属，任务适配的汇总与回投 | 不是RGB与SAR对齐算法；官方老PyTorch及连通性扩展需适配。中成本 |
| SEAL，CVPR 2018；[论文](https://openaccess.thecvf.com/content_cvpr_2018/html/Tu_Learning_Superpixels_With_CVPR_2018_paper.html)、[官方代码](https://github.com/wctu/SEAL) | 从分割标注学习邻接亲和性，再图分割 | 用分割错误监督相似关系，而非只换更强特征 | 官方仓库主要提供测试模型和评估，不是完整训练即插即用；建筑二值亲和性仍不保证损毁判别。中至高成本 |
| Superpixel Transformers，IROS 2023；[论文](https://arxiv.org/abs/2309.16889) | RGB语义分割；局部双向注意力、区域自注意力及最终语义监督 | 压缩后还需判别推理；Transformer与超像素不矛盾 | 不是单纯均值Pooling，也没有必须配Memory；本轮未核实作者官方训练仓库，不能冒用同名第三方仓库。高成本 |
| SPAM，BMVC 2025；[论文](https://bmva-archive.org.uk/bmvc/2025/assets/papers/Paper_1035/paper.pdf)、[官方代码](https://github.com/waldo-j/spam) | RGB超像素；分割及紧致度训练，推理使用对象先验 | 对象相关种子、受约束候选、不确定区域、连通性处理 | 先验掩膜不是BRIGHT真实建筑；错误B不能升级成不可违反真值。不能一次替换全部模块。中至高成本 |

这里的新近对象先验路线以SPAM为例，说明可研究先验可靠性与种子预算，而非必须换主干。SSN式可微分区、直接归属预测、对象先验、区域上下文都已有文献；创新只能来自经过公平实验验证的任务适配，不是模块名组合。

## 如何控制而不是穷举变量

先把现有固定hard配置作为参照，记录权重hash、数据列表、原图与Q尺寸、所有聚类常数、B阈值、读出初始化、实际更新次数、有效batch和验证规则。读出训练中冻结前端与运行统计，不能只冻结参数却让BatchNorm继续更新。

如果下一项是Memory实验，保持前端、Q、B、hard路由、Embedding和原区域分类器全部不变。比较同初始化、同容量的新修正头，有真实Train邻居与无真实邻居的差异。任何生成器或Embedding改变都需要独立实验和匹配的重新建库。

如果下一项是分区研究，先只读诊断再决定唯一改动：

1. **尺度问题**：小对象常被与其他GT等级混合、且误差集中于粗区域，才比较s=8与一个预先选定的更细尺度，例如4。1024图下种子从1024增为4096，最多槽位从2048增为8192；这是粒度及预算变化，不能称为完全等预算的算法优越性。
2. **迭代问题**：先在固定描述、固定种子下检查T=1、3、5的Q变化及耗时。如果3至5几乎不变，不优先增加迭代；若明显变化，还需相同预算训练各自读出才比较分类。推理时改T只属于敏感性检查。
3. **定位约束问题**：只有伤害按B置信度和定位FN/FP统计指向硬规则，才研究不确定位置回退。高置信度定位错误不能靠0.5附近阈值微调自动解决。

以上是选择条件，不是三组同时开跑的清单。现有三个负结果也不构成重新搜索所有温度、种子数、学习率的理由。

## 三个保留候选与停止条件

### BRIGHT小建筑证据的超像素尺度适配

假设是固定种子尺度没有适应建筑在特征图上的大小。借鉴SLIC及对象先验分区对尺度和种子的处理，先做Train尺度统计，再以固定描述网络、B、读出结构和训练预算比较原尺度与一个候选尺度。先不加Memory、SAR新分支或额外损失。

希望观察小对象和边界净伤害下降，并且不是仅靠背景误报变化涨分。若分区更纯但分类无稳定改善、微小质量槽位更多或计算代价失衡，就停止加密。未证明尺度瓶颈之前不实现自适应种子系统。

### RGB与SAR建筑分组中的可靠性回退

假设是错误B导致的证据隔离可被有限回退纠正。借鉴SPAM不确定区域的思想，但不假定B能可靠识别所有错误。Q与内容不变，只修改经过诊断选定的一端支持规则，记录接收端注意力前后异组比例。

若错误定位处的收益继续被正确定位处的伤害抵消，停止增加交换范围或比例。接收端控制属于待验证任务假设，不是已经证明的根因修复。

### 固定超像素表示的跨事件历史证据检验

按现有Memory实现，固定全部区域表示，比较独立训练的memory与nomemory修正头。库只来自Train，查询GT不能参与检索或筛选，原hard输出保留为锚点。

若Memory不优于同容量无Memory头，就不能把效果归因于历史知识；近邻质量低时先检查特征距离、事件差异和混合标签，不同时解冻Q。当前只是可证伪对照，不是Memory有效性的预设。

## 共同评价规则

全图前景mIoU为主，同时报告三个前景IoU、Damaged P/R/F1、Damaged与Intact等完整混淆变化、ROI定位TP/FN/FP/TN、边界内外侧、小对象代理、每事件结果、实际区域数、空或微小质量区域、耗时和显存。分区质量分别按背景、前景及各损毁类别统计，不能只给背景占主导的全图纯度。

ASA是假设区域类别可由GT最优指派的诊断准确率，不是当前模型的前景mIoU上限。更高纯度、连通性或边界召回都不能代替最终任务评价。统计不确定性用配对图像或场景单位；独立种子波动另报，不把像素或连续验证轮次当独立样本。

固定终点是主要比较，各组最佳点作为次要记录。先规定什么幅度及错误改善值得追加种子；出现实质正向信号才扩大验证，不用Test选参数。若最小变化没有改善，就保留当前参照或停止这条分区扩展，不强行寻找必涨模块。
