## 4. 最优先补哪三组实验

1. 表3(a)：B→Q开关×结构Adapter开关的2×2。四组统一采用区域特征直接Q回投与F联合分类，不设Reader或支持槽，匹配其余条件。验证“区域成员”和“区域内容”是否分别有效及有无交互。
2. 表4：像素头适配→像素–区域融合→参数化支持→真实余弦支持→监督检索。匹配训练预算、区域前端和库，区分当前上下文、读取器容量和历史案例。
3. 表5：固定同一Reader、联合头、Q和库，只替换邻居ID。比较余弦、跨事件监督、随机合格支持，分别报告检索相关性和最终分类。可用混合排序训练Reader，或做完整交叉替换。

随后补表3(b)固定Q的条件/容量对照，表6支持标签与元数据的独立消融，以及逐事件、至少3种子、延迟/显存。表6已把去事件ID、去灾种、去几何拆成独立行，避免三个操作只填一个成绩。

## 6. 40篇文献怎样核验

正文40篇全部被引用，题名唯一，没有新闻稿，没有将同一论文预印本和会议版重复计数。8篇取得全文或作者PDF/既有出版社文本提取，32篇主要核对作者/机构书目和学术引用记录；不能称40篇全部阅读全文。

references_40_audit.xlsx逐条列出作者、年、刊会、已核卷页/DOI、论文入口、代码入口、核验等级、来源和未确认字段。references_40.bib可导入文献软件，references_40.json保留来源路径和SHA。出版社/Crossref等部分接口本轮受限，未确认卷页/DOI不补造。Attention采用核实的arXiv学术论文版本；SPAM的BMVC归属以作者书目核对，不伪称读取会议全文。SRAC会议目录和新闻不计入这40篇；若取得正式全文，后续可补入相近工作，但须相应调整总数和引用编号。
