# HRM：层级目标与 Correct/Residual 双病例库

本实验承接 QSD-RCM 的失败结论，不修改 P3、不做像素写回，也不访问 meta_confirm、Val450 或 test。

## 连续回答两个问题

1. `D1 Target Granularity`：当前建筑卡最多能稳定检索到 P3来源、GT类别、Affected状态、P3是否错误、错误家族，还是完整修正方向。
2. `E0 Dual Bank`：将历史病例拆成 P3正确库和P3错误库，比较查询与两个库的相似度差，测试能否识别P3错误。

训练批次固定为：40%错误同家族正对、30%错误困难负对、20%正确正对、10%正确/错误负对。全部病例对必须来自不同事件。

最终必须超过打乱库和P3自身不确定性，才能说明Memory提供了独立错误信息。否则停止Memory模型集成。
