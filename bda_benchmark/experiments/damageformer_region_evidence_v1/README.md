# 区域混合、固定Q干预、同特征分类对照

独立目录，引用但不修改V2及其依赖。当前训练不自动停止；单GPU请避免与训练竞争。
所有数据来自标准Train2918/Val450；禁止Test。输入必须是匹配V2源码哈希的固定前端checkpoint。
输出新目录，不覆盖、不自动删除、不恢复旧实验。运行时不编辑V2，避免破坏哈希。

## 入口

run.sh preflight：3项CPU合约测试与入口检查。
设置FRONT_CKPT、OUTPUT_ROOT；run.sh smoke_audit / audit。
更换OUTPUT_ROOT；run.sh smoke_heads / train_heads。
smoke使用2张Val；heads烟测20步，不用于效果判断。
正式heads默认5000步、每500步Val、BATCH2×ACCUM8，两个头同一批特征同时独立优化。

## 第一层：区域混合统计

regions.csv.gz逐图逐区域保存：软有效面积、四类纯度、建筑/背景少数占比、前景类别混合度、
硬分区特征格连通块数、硬分区跨GT前景连通域数量、有效像素数、pixel正确/错误、region伤害/救回。
GT标签先转有效one-hot后area缩小，按Q加权汇总，再换算原图像素等效面积；ignore255不作背景。
纯度没有有效质量时为None，不计作0；硬分区由argmax(Q)得到，再最近邻映射到原图用于错误归属。
纯度分桶预设>=.95、.8..95、<.8；另有跨GT连通域组，可与纯度组重叠。
伤害率=harm/base_correct，救回率=rescue/base_wrong；零分母为None。
summary包含全图类别混淆矩阵、逐事件指标、GT×pixel×候选预测转移表。
GT仅用于评估，没有输入分区或调制。GT连通域不是建筑实例。相关性不是因果，
不同事件、类别、尺寸可能混杂。软分区统计与硬分区错误归属不是同一个数学对象，均显式标注。

## 第二层：固定Q图像调制干预

正常：原背景衰减和边界突出；off：floor=1,strength=0；
dim_only：保持原floor，strength=0；edge_only：floor=1，保持原strength。
每图只执行一次原V2 forward，缓存Q/候选ID/建筑概率/SAR特征。
干预时只重算调制RGB内容路径和区域分类，不再调用分区器，也不修改model.config。
修复旧版每次重新计算Q后要求逐位相等的问题；不靠放宽误差阈值绕过固定Q要求。
全模型eval、无梯度、BN原始统计不变。
每图断言Q/候选ID完全相同，pixel输出完全相同。只干预区域路径的输入图像调制；
没有修改pixel分支Soft ROI、区域汇总、分类头。捕获第二次fusion_layer_3输出作为区域内容特征。
关闭调制也仍走第二次编码路径，以保持接口。结果是分布扰动，不等于重新训练的消融。
不称off为"完全无建筑先验模型"，因为参数曾在含先验的训练下学习。

## 第三层：同一特征上的新头诊断

固定同一V2前端，模型始终eval且requires_grad=False；原分类头不更新。
每批提取同一张调制后融合特征图F与同一Q，两个头从完全相同状态初始化：
LayerNorm(256) → Linear(256,128) → GELU → Linear(128,4)。
pixel：逐位置MLP，softmax后双线性上采样；region：Q均值汇总F，MLP分类，区域概率经Q回投。
两者完全相同参数数、全图NLL+Lovasz监督、数据顺序、AdamW1e-4/WD.005/裁剪1；
独立优化器、各自梯度裁剪；共享的只有冻结特征，不互相反传。
FP32；5000步诊断自己的warmup(最多100)+cosine，与旧50k前端训练不是同一任务，不能比较loss值。
这是只隔离"先汇总再分类"的均值Pooling探针，故意不复制旧注意力/mean-std旁路。
不能宣称它覆盖了完整V2区域表示的所有问题；如果它比旧头好，仍需分解容量和训练差异。
每次Val同时输出old_pixel、old_region、pixel、region；前两项应保持固定，是自检。
完整运行先核验old_region复现checkpoint指标；如未通过则停止，不改阈值强行继续。
只保存每个新头best/last及优化器，不保存整套主干、不缓存全Train特征，节省磁盘。
新头检查点不是V2前端/Memory权重，不可混用。输入checkpoint仍需保留。
比较同时刻曲线和各自best；单种子仅筛查，不能声称统计显著。

## 判读顺序

1. 正常路径先复现；混合桶用分母比较，不只看错误总数。
2. 调制干预若改善，支持进一步做该调制项的重新训练对照，不立刻删除模块。
3. 新像素头明显优于新区域头：该特征与Q下聚合/回投有代价；两者都差：还需检查特征、头和优化。
4. 新头均好但旧region差：优先检查旧区域表示/分类训练组合，而不是宣称Q失效。
不添加Memory、建筑硬分组、新损失；先取得证据再改模型。
