# 2026-10-08：RGB–SAR Q 明确化与检索距离实验依据

## 研究问题与当前证据

保留 DamageFormer 双 Swin 与 A1 Soft ROI 的内容特征，检验两个独立假设：
H-Q：过于分散的区域归属可能损失判别信息；H-M：原区域 Token 的余弦距离可能更关注外观/事件而非损毁等级。
高熵与 smoke 检索混淆不是因果证据，正式父流程尚需完成。Q 改进与检索距离改进不能在第一轮合并。

## 三个可执行验证点

1. **Q日程对照**：同A1、同初始权重、同预算下，beta1与1→2。看分割而非超像素外观；Q熵降低但分类下降则否定。
2. **检索空间验证**：同一Train库，128×128映射，仅改变排序。Train纯区与跨事件类别对比拟合，Val逐类诊断但不用于拟合。缺少正对时报告覆盖不足，不构造伪标签强行补齐。
3. **保留像素证据的联合读出验证**：J0/J1/J2/J3同图像同初值，重点J3−J2。kNN变好而J3不变，说明检索改善没有转换为最终增益，不能继续宣称成功。

## 对当前任务的具体适配

建筑/背景预测仍然是软先验，不增加“只能属于一个建筑实例”的错误承诺。允许SAR证据通过原融合特征参与分类，不对灾前光学轮廓外SAR做硬裁剪。
Damaged/Destroyed必须单独报告正对事件数、同类近邻覆盖/比例，以及最终P/R/F1。四类总体kNN容易被Background主导。
Memory只存Train样本；任何查询推理都没有GT入口。同事件和同图像都排除。投影训练高纯度筛选不会改变对照组与新组使用的支持库。

## 代价与负面结果

Q更明确可能放大错误的预测建筑先验，也可能造成不合适的小区域。beta的作用可能被可学习相似度尺度抵消。
检索线性映射可能在有限Train库上过拟合，跨事件同类差异太大也可能使对比目标不适用。它不能“凭空记住”库里不存在的稀有类证据。
新投影额外2000步应单列训练预算；本版不宣称与零附加训练成本对照完全相同。正向后再做预算/随机或无标签投影控制及多种子确认。

## 创新边界

可微超像素、温度控制、监督对比和跨图像语义对比都是已有思想。这里的新假设是它们在固定DamageFormer/SoftROI、区域任务和跨事件检索中的具体适配，尚无有效性结论。
联合分类器沿用旧实现，不作为新创新点；不承诺75%或可靠超越A1。先以可证伪实验找到瓶颈，再决定论文主张。
